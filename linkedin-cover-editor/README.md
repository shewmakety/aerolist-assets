# LinkedIn Cover Editor

A 1200x628 PNG LinkedIn post/article cover maker with a title, a series label, a title size, optional small text, and an optional right-side image. It is a single-page, browser-only tool.

## Live Page

The live page is https://aerolist-masthead.ty-shewmake.workers.dev/.

The Cloudflare Worker `aerolist-masthead` was created on 2026-10-12 and last modified on 2026-10-16. It has no bindings.

## Local Copy

This copy was taken from the live page. `index.html` is that page, saved as served, with its images inlined.

## Open Locally

Open `index.html` in a browser.

## Redeploy

From this folder, with `CLOUDFLARE_API_TOKEN` set in the environment:

```sh
npx wrangler deploy
```
